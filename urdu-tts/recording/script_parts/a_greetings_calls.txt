میں آپ کی منیجر صاحب سے بات کروا دیتا ہوں۔
جی، صاحب ابھی میٹنگ میں ہیں، کوئی پیغام ہو تو دے دیں۔
وہ ابھی سیٹ پر نہیں ہیں، آدھے گھنٹے تک آ جائیں گے۔
میں آپ کا میسج ان تک ضرور پہنچا دوں گا۔
آپ کس سے بات کرنا چاہیں گے؟
ایک لمحہ، میں ان کی ایکسٹینشن ملاتا ہوں۔
ہیلو، جی میں بلال ہوں، احمد نے مجھے آپ کی ساری بات بتائی ہے۔
ابھی ان کی لائن نہیں لگ رہی، میں دوبارہ کوشش کرتا ہوں۔
یہ کام میرے اختیار میں نہیں ہے، لیکن میں آپ کو صحیح بندے تک پہنچا دیتا ہوں۔
آپ کو دوسرے شعبے میں بھیج رہا ہوں، ایک دو منٹ لگیں گے۔
فکر نہ کریں، آپ کی بات ضائع نہیں ہوگی۔
اور کوئی خدمت ہو تو بتائیں؟
کیا میں آپ کی کسی اور چیز میں مدد کر سکتا ہوں؟
نہیں جی، بس یہی تھا، شکریہ۔
چلیں جی، پھر اجازت دیں۔
اللہ حافظ، اپنا خیال رکھیے گا۔
خدا حافظ، آپ کا دن اچھا گزرے۔
چلو یار، پھر بات ہوتی ہے۔
ٹھیک ہے، میں کل آپ کو دوبارہ کال کروں گا۔
بات کر کے بہت اچھا لگا، پھر ملیں گے۔
بول کو کال کرنے کا شکریہ، اللہ حافظ۔
کوئی بھی مسئلہ ہو تو بلا جھجک کال کیجیے گا۔
ہم ہر وقت آپ کی خدمت کے لیے حاضر ہیں۔
گھر میں سب کو میرا سلام کہیے گا۔
گھر والوں کو سلام دینا یار۔
چلیں، آپ کو مزید تنگ نہیں کرتا۔
اچھا جی، میں اب فون رکھتا ہوں۔
کال کے آخر میں ایک چھوٹا سا سروے ہوگا، اگر آپ کے پاس وقت ہو۔
آپ کی شام خوشگوار گزرے۔
شب بخیر، اب آرام کریں۔
جلدی ملاقات ہوگی، ان شاء اللہ۔
جی، اگر آپ کو برا نہ لگے تو کیا میں آپ کا اکاؤنٹ نمبر لے سکتا ہوں؟
کیا آپ مجھے اپنے شناختی کارڈ کے آخری چار ہندسے بتا سکتے ہیں؟
آپ کی پرائیویسی ہمارے لیے بہت اہم ہے، یہ معلومات کسی کو نہیں دی جائیں گی۔
مہربانی کر کے تھوڑا آہستہ بولیں، میں سب نوٹ کر رہا ہوں۔
براہِ مہربانی اپنا رجسٹرڈ نمبر بتا دیں۔
جی، آرام سے، کوئی جلدی نہیں ہے۔
آپ بالکل فکر نہ کریں، ہم آپ کے ساتھ ہیں۔
اگر آپ اجازت دیں تو میں ایک دو سوال پوچھ لوں؟
آپ کو یہ معلومات کیسی لگی، کچھ اور جاننا چاہیں گے؟
جی، میں پوری کوشش کروں گا کہ آج ہی آپ کا کام ہو جائے۔
دیکھیں، میں آپ سے جھوٹ نہیں بولوں گا، اس میں دو تین دن لگیں گے۔
میں سمجھ رہا ہوں آپ کو جلدی ہے، میں اسے ارجنٹ کر دیتا ہوں۔
آپ کا غصہ بالکل جائز ہے، لیکن مجھے ایک موقع دیں۔
تھوڑا صبر کیجیے، میں سب ٹھیک کروا دوں گا۔
ٹھنڈے دل سے سنیں، میں پوری بات سمجھاتا ہوں۔
جی، آپ کی بات بالکل درست ہے، ہم سے چوک ہو گئی۔
اگر کوئی اور سوال ذہن میں آئے تو بلا جھجک پوچھیں۔
میں آپ کو ایک ایک قدم پر گائیڈ کرتا ہوں، فکر نہ کریں۔
جیسے ہی اپڈیٹ آئے گی، میں آپ کو خود فون کر کے بتاؤں گا۔
آپ کا ٹکٹ نمبر لکھ لیں، آگے کام آئے گا۔
ابھی تھوڑا رش ہے، اس لیے جواب میں دیر ہو رہی ہے۔
آپ کا پیکج کل شام تک آپ کے گھر پہنچ جائے گا۔
رائیڈر نے بتایا ہے کہ وہ گلی کے کونے پر کھڑا ہے۔
جی، ڈرائیور راستے میں ہے، بس دس منٹ میں پہنچ جائے گا۔
کیا آپ کو جگہ ڈھونڈنے میں کوئی دقت ہو رہی ہے؟
گیٹ کے باہر جو سفید گاڑی کھڑی ہے، وہی آپ کی ہے۔
اگلے موڑ سے بائیں مڑ جائیں، وہاں سے سیدھا راستہ ہے۔
بھائی، ذرا دروازے پر آ جائیں، ڈیلیوری والا کھڑا ہے۔
اچھا تو آپ کو خراب پیس ملا ہے، تصویر بھیج دیں گے؟
ہم وہ چیز بغیر کسی چارج کے بدل دیں گے۔
یار، تم سے بات کر کے دل خوش ہو گیا۔
تم بتاؤ، تمہارے ہاں سب ٹھیک ہے؟
کب آ رہے ہو لاہور؟ کھانا اکٹھے کھائیں گے۔
ارے یار، آج تو بڑی دھوپ ہے، باہر نکلنا مشکل ہے۔
ٹھنڈ بڑھ گئی ہے، گرم کپڑے نکال لیے؟
گھبرانے کی کوئی بات نہیں، سب ٹھیک ہو جائے گا۔
آپ کے لیے ڈھیر ساری دعائیں۔
بھئی واہ، کیا بات ہے آپ کی!
چھوٹا سا کام ہے، جلدی ہو جائے گا۔
کھڑے کھڑے ہی بات کر رہا ہوں، بس نکلنے لگا ہوں۔
جھجکیں مت، جو بھی بات ہے کھل کر بتائیں۔
غلطی کسی سے بھی ہو سکتی ہے، دل پر مت لیں۔
بڑی خوشی ہوئی یہ سن کر کہ آپ کا مسئلہ حل ہو گیا۔
قسم سے، مجھے بھی آپ سے گپ شپ کر کے بہت مزہ آیا۔
خیریت سے پہنچ گئے؟ راستے میں کوئی تکلیف تو نہیں ہوئی؟
ٹھیک ہے، میں تھوڑی دیر میں فون گھماتا ہوں۔
جی، میں ابھی گاڑی چلا رہا ہوں، کیا بعد میں بات کر لیں؟
میں نماز پڑھ کر آپ کو کال بیک کرتا ہوں۔
گڈ مارننگ جی، آج آپ بڑے خوش لگ رہے ہیں۔
آج آپ کی آواز میں بڑی تازگی ہے، خیر تو ہے؟
اچھا، اپنا اکاؤنٹ نمبر ذرا ایک ایک کر کے بتائیں۔
آپ نے بالکل ٹھیک جگہ کال کی ہے۔
یہ سوال اکثر لوگ پوچھتے ہیں، بالکل جائز سوال ہے۔
مجھے تھوڑا اندازہ تھا کہ آپ یہی پوچھیں گے۔
دیکھیں جی، کچھ چیزیں ہمارے ہاتھ میں نہیں ہوتیں۔
کوئی بھی کنفیوژن ہو تو مجھ سے پوچھ لیجیے گا۔
آپ کا ٹیلی ویژن والا آرڈر کل ڈسپیچ ہو جائے گا۔
بس جی، آپ دعاؤں میں یاد رکھیے گا۔
اچھا جی، تو پھر طے ہو گیا، کل ملتے ہیں۔
بہت شکریہ آپ کے وقت کا، اللہ حافظ!
